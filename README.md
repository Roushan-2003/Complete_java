## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Roushan-2003/Complete_java.git
```

Navigate to the project folder:

```bash
cd Complete_java
```

Compile a Java program:

```bash
javac FileName.java
```

Run the program:

```bash
java FileName
```
